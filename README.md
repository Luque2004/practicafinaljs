# Academia de Muay Thai: web con reservas

Web de una academia de Muay Thai, Boxeo y BJJ en Collblanc (L'Hospitalet de Llobregat), hecha como práctica final de JavaScript.

**[Ver la web](https://luque2004.github.io/practicafinaljs/)**

## Qué hace

- **Formulario de reserva de clases:** al elegir la clase y el día, el desplegable de horas se rellena solo con el horario que corresponde a esa clase.
- **Validación del formulario** antes de enviarlo y **envío por correo** con EmailJS, sin backend.
- **Mapa de Google Maps** con la ubicación de la academia.
- **Interacciones:** tarjetas que se resaltan al pasar el ratón (jQuery) y desplazamiento suave hasta el formulario (CSS).

## Tecnologías

HTML5 · CSS3 · JavaScript · jQuery · Google Maps JavaScript API · EmailJS

## Estructura

```
index.html
css/                 estilos (reset + style)
javascript/          lógica del formulario, mapa e interacciones (jQuery)
img/                 logo, banner y horario
```
